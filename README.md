## ✨ Projects

| Folder | Dataset | What's inside |
|---|---|---|
| `1/` | 🌍 **Life Expectancy** (WHO) | `led.ipynb` - cleaning, EDA and plots; `done.csv` is the cleaned data |
| `2/` | 📑 Excel dataset | `eda.ipynb` - EDA on the worksheet; `done.xlsx` is the cleaned output |
| `3/` | 🏠 **House prices** (Ames-style, `train.csv` + `data_description.txt`) | `eda.ipynb` and `feature_select.ipynb` - cleaning and feature selection |
| `4/` | 🍽️ **Zomato restaurants** (`zomato.csv`, `Country-Code.xlsx`) | `eda.ipynb` - restaurant data exploration |
| `5/` | 📊 Train / test dataset | `ed.ipynb` - EDA notebook |

## 🚀 Getting Started

```bash
git clone https://github.com/Arashomranpour/eda.git
cd eda
pip install pandas numpy matplotlib seaborn openpyxl jupyter
jupyter notebook
```

Open the notebook of the project you want to explore (run it from its own folder so the relative data paths resolve).
